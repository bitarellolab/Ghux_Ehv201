Files in this folder are large and so the directory is in the .gitignore list. These files are provided elsewhere, so when cloning the repo, make sure to copy the appropriate files into this directory to run the scripts (or adjust the paths accordingly).


Important: fastp and salmon sample names are as they came from Upenn, i.e, prior to fixing all the mislabelled samples.

FASTQ/

Raw fastq files from UPenn sequencing core. 

fastp-v024/

folder containing output from fastp run. Contains three subfolders:



fastp-v024/fastp-out/

Folder containing output files from running fastp (v0.24) command:

`fastp -i sample_READ1.fastq.gz -I sample_READ2.fastq.gz -o sample.out.r1.fp.fq.gz -O sample.out.r2.fp.fq.gz -h sample.html -j sample.json --unpaired1 sample_unpaired1 --unpaired2 sample_unpaired2 --detect_adapter_for_pe`


fastp-v024/fastp-plots/

Plots generated by running multiqc on all the output FASTQ files.

fastp-v024/fastp-files/

Files generated by running multiqc on all the output FASTQ files.


salmonI-v1.10.3/

Input and output files related to running the indexing step ("salmon index") of the mapping-based read quantification. 

salmonQ-v1.10.3/

Output files from running the salmon quantification step of the mapping-based read quantification ("salmon quant"). Note comment at the top about mislabelled samples. 

File `salmon-output-79samples.tsv.gz` inside this folder contains read counts for 79 samples (HHQ_cntl_t1_3 excluded). Note: sample names are correct in this file but not in the salmon output files. 
multiqc-reports/

Multiqc html reports + figures + tables generated by multiqc for the fastp and salmon runs.
